## 🏗️ Архитектура (Обновлено)
### Стек
- **Framework:** Next.js 14 (App Router)
- **Database:** Supabase (PostgreSQL + RLS)
- **Automation:** Supabase Edge Functions + pg_cron
- **Bot:** Telegram Bot API (webhook)

### Ключевая логика (Phase 11 Updates)
1. **Персонализация наград:** Кнопка «Забрать подарок» динамически меняет ссылку на основе ответа пользователя о «сфере напряжения» (деньги, отношения, здоровье, другое).
2. **Прогрев Share-триггера:** Перед открытием нативного окна Telegram `utils.shareURL()` система отправляет API-запрос для инициации сообщений от бота.
3. **Система возврата (Retention):** - **24 часа:** Проверка, прошел ли реферал тест после клика «Поделиться».
   - **60 дней:** Автоматическое напоминание о ретесте.

---

## 📐 База данных (Актуальные точки для аудита)
- **`profiles`**: Необходима проверка колонки `shared_at` (timestamp) для трекинга 24-часового окна.
- **`test_results`**: Содержит данные о «сфере напряжения» для маппинга динамических подарков.
