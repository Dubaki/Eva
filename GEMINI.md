# Контекст разработки проекта EVA

## 1. Реферальная система (Вторая опора) — ИСПРАВЛЕНО
- **Цель:** Когда 2 реферала пользователя проходят тест, пользователю мгновенно приходит сообщение со "Второй опорой".
- **Логика начисления:** 
  1. В `app/api/test/submit/route.ts` при завершении теста (25-й вопрос) ищется пригласитель (по `referred_by`).
  2. Приглашителю начисляется `invites_count + 1`.
  3. В профиль реферала ставится "печать" `referrer_id` (UUID пригласителя), чтобы избежать повторных начислений.
- **Логика уведомления:**
  1. В Supabase настроен вебхук `send_referral_bonus` на таблицу `profiles` (событие UPDATE).
  2. Edge-функция `process-bot-notifications` ловит изменение `invites_count` с любого значения на **2**.
  3. Бот берет данные из таблицы `test_results` (колонки `primary_support`, `secondary_support`) и отправляет текст.
- **Критическое обновление (21.04.2026):**
  - **Колонки БД:** Везде в коде (типы, бот, API, админка) закреплены названия `primary_support` и `secondary_support` для таблицы `test_results`. Старые названия (`dominant_trait`, `shadow_trait`) удалены.
  - **RPC:** Функция `save_test_result` пересоздана в Supabase с поддержкой новых имен колонок.
  - **Edge Function:** Код `process-bot-notifications` полностью очищен от посторонней логики (напоминаний) и теперь корректно отправляет результаты тестов и подарки за рефералов.

## 2. Периодические напоминания (60 дней)
- **Функция:** `send-periodic-reminders`.
- **Логика:** Ищет пользователей с `last_test_date` >= 60 дней и `reminded_at IS NULL`.
- **Цикличность:** При каждом новом прохождении теста в `submit/route.ts` колонка `reminded_at` сбрасывается в `NULL`, чтобы через 60 дней напоминание пришло снова.

## 3. Админ-панель
- **Секретный вход:** На главной странице (Gatekeeper) заголовок "Сейчас нет смысла проходить тест заново" стал кликабельным. Ведет на `/admin`.
- **Обновление:** Теперь статистика и список пользователей корректно отображают опоры (`primary_support`).

## 4. Технический стек и зависимости
- **База данных:** Supabase (PostgreSQL).
- **Хостинг:** Vercel (Next.js App Router).
- **Бот:** Telegram Bot API (Webhooks).
- **Важно:** Все изменения в коде должны быть синхронизированы с Edge-функциями Supabase вручную или через CLI (`supabase functions deploy`).
