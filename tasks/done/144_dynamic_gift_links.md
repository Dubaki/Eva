<context>
Необходимо сделать кнопку "Забрать приз" ("Забрать подарок") динамической. Ссылка должна зависеть от ответа пользователя на вопрос о сфере напряжения ("В какой сфере ты сейчас сильнее всего чувствуешь напряжение?"). Ссылки для каждой сферы уже настраиваются и хранятся через админ-панель (gift_money, gift_relations, gift_health, gift_other).
</context>

<task>
1. **Получение ответа пользователя:** Найти место в состоянии приложения (или в `test_results`), где хранится ответ на вопрос "В какой сфере ты сейчас сильнее всего чувствуешь напряжение?".
2. **Получение ссылок:** В компоненте экрана результатов добавить запрос к API (например, `/api/gifts` или аналогичный роут, отдающий публичные ссылки), чтобы получить актуальные линки.
3. **Настройка маршрутизации (Мэппинг):** Написать функцию для кнопки "Забрать приз", которая проверяет ответ пользователя:
   - Если ответ связан с финансами/работой -> использовать `gift_money`
   - Если ответ связан с отношениями -> использовать `gift_relations`
   - Если ответ связан со здоровьем/состоянием -> использовать `gift_health`
   - Если ответ "Другое" ИЛИ "Везде" -> использовать `gift_other`
4. **Обновление кнопки:** Привязать открытие выбранной ссылки (через `window.Telegram.WebApp.openLink` или `window.open`) к клику по кнопке. 
5. Перенести этот файл из папки `tasks/todo/` в папку `tasks/done/` после деплоя.
</task>

<rules>
- Ссылки должны загружаться динамически (чтобы при изменении их в админке они сразу менялись у пользователей).
- Если по какой-то причине ссылка пустая (не задана в админке), кнопка не должна ломать приложение (добавь fallback-поведение, например, скрытие кнопки или `gift_other` по умолчанию).

</rules>
